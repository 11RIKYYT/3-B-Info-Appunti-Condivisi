# Appunti Condivisi - 3°B Info Jean Monnet

Questa repository è dedicata alla condivisione di appunti, compiti, esercizi e verifiche tra gli studenti della 3°B Informatica dello Jean Monnet.

## 📚 Convenzione per i branch temporanei

Per mantenere ordine e sicurezza nella repository, quando crei un branch temporaneo devi seguire questa convenzione di nome:

    appunti-nome-argomento

Esempi:

    appunti-Luca-matematica
    appunti-Giulia-informatica
    appunti-Marco-storia

⚠️ Solo i branch che seguono questo pattern saranno accettati e protetti dalle regole della repository!

Perché lo facciamo?

Per sapere subito chi ha creato il branch e su quale argomento lavora.
Per rispettare le regole di protezione e sicurezza.
Per facilitare le revisioni e il lavoro di gruppo.
Se hai dubbi su come creare un branch, chiedi pure!

## 📁 Struttura delle cartelle

Ogni materia ha la sua cartella principale (es: `Informatica`, `Matematica`, ecc.).

All’interno di ogni materia ci sono le seguenti sottocartelle:
- `Appunti`
- `Compiti`
- `Esercizi`
- `Verifiche`

All’interno di ciascuna sottocartella, se non già presente, crea una cartella con la **data** in cui è stato svolto il lavoro (formato consigliato: `DD-MM-YYYY`).
Inserisci i tuoi file nella cartella della data corretta.

**Esempio di struttura:**
Informatica/ Appunti/ 18-09-2025/

    MarioRossi_AlgoritmiOrdinamento.pdf
    LucaBianchi_AlgoritmiOrdinamento.pdf

Compiti/ 02-10-2025/

    MartaVerdi_CompitoSQL.docx
    MarioRossi_CompitoSQL.pdf

Esercizi/ 20-09-2025/

    LucaBianchi_EserciziRicorsione.txt

Verifiche/ 10-11-2025/

    MarioRossi_VerificaAlgoritmi.pdf


## 📄 Regole per i nomi dei file

- Ogni file deve essere nominato così: NomeCognome_NomeCompito.ext (.ext è l'estensione del file, ATTENZIONE può essere diversa!)

- **NomeCognome:** Il tuo nome e cognome senza spazi (es: MarioRossi)
- **NomeCompito:** Il nome dell’argomento, compito o verifica (es: AlgoritmiOrdinamento, CompitoSQL...)
- **ext:** L’estensione del file (.pdf, .docx, .txt, ecc.)

**Esempi di nomi file:**
- MarioRossi_AlgoritmiOrdinamento.pdf
- LucaBianchi_CompitoSQL.docx
- MartaVerdi_VerificaAlgoritmi.pdf

## 📝 Consigli e Buone Pratiche

- Usa sempre la cartella della materia giusta.
- Inserisci ogni file nella sottocartella della data corrispondente.
- Rispetta la convenzione dei nomi, così tutti troveranno facilmente i materiali.
- Se hai dubbi su dove mettere un file, chiedi al gruppo!
